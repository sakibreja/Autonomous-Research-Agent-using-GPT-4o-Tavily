# Autonomous-Research-Agent-using-GPT-4o-Tavily
🔍 Just launched my latest AI project — "Autonomous Research Agent using GPT-4o + Tavily" 🚀
Meet a smart multi-agent system that can automatically conduct research, retrieve web data, and present insights — all by simply giving it a prompt.

🧠 Built with:
Python, AutoGen by Microsoft, Tavily API, OpenAI GPT-4o, and .env for secure config

💡 What it does:
A User Proxy Agent talks to a GPT-4o Assistant Agent. The Assistant leverages real-time web data using Tavily to research topics and return well-structured responses autonomously.
